# Fixtures

- `sessions/` — observation sessions (`skyfix.session/1`). Simulated sessions never contain truth.
- `expected/` — `<name>.truth.json` (`skyfix.truth/1`) for simulated sessions, and
  `<name>.expected.json` independently derived expected outputs for solver/reduction tests.
- `reference/` — astronomy reference cases (`skyfix.reference/1`) generated by
  `tools/reference/` (Python + Skyfield, development-time only) or typed from an
  independent published source. Each file records its generator, ephemeris, EOP
  assumptions, refraction convention and tolerance. Never regenerate these from Rust output.

See `docs/CONVENTIONS.md` sections 10-11.
