# Proper names for the brighter stars. SkyFix Lab star field, display only.
#
# Star names are facts: these are the names in common use, which for most stars are the
# ones the IAU Working Group on Star Names has catalogued. For the 57 Nautical Almanac
# navigational stars and Polaris the spelling is the Almanac's ("Al Na'ir", "Rigil
# Kentaurus"), because that is the spelling used everywhere else in SkyFix Lab; the build
# checks this against skyfix-ephemeris's catalogue.
#
# Format: <designation> = <name>. A designation is a Bayer letter (BSC abbreviation,
# optional superscript digit) and constellation, a Flamsteed number and constellation,
# or "HR <n>". Without a superscript the brightest catalogue star with that letter is
# meant (so "Alp Cru" is alpha-1 Crucis). tools/starfield/build.py resolves each line to
# an HR number and refuses any that does not resolve.
