# Meteor showers. SkyFix Lab's own table, display only (CONVENTIONS 13.6).
#
# Compiled for this project from the published values of the IAU Meteor Data Center
# (established showers, MDC 2022, updated 2026-09-21) and the International Meteor
# Organization's 2026 and 2027 meteor shower calendars (Table 5). Values are facts;
# neither source's table or prose is copied. tools/starfield/showers.py checks every
# row against both sources and writes crates/skyfix-starfield/data/showers.txt.
#
# Selection: every shower the IAU MDC lists as established (status 1 or 2) whose
# radiant can be seen at night and that the IMO lists for visual observers with a
# typical peak ZHR of 2 or more or as variable. Left out on that rule: the daytime
# Arietids and Sextantids, the Puppid-Velids, September Lyncids and alpha-Centaurids
# (not established in the MDC), the Antihelion Source (not a shower) and the
# Andromedids (listed only for a predicted return in 2027).
#
# Columns:
#   iau, code, name        IAU number and code; our English name
#   lambda start/peak/end  solar longitude, J2000, degrees: the peak is the IMO's; the
#                          activity limits are the IMO's 2026 dates at 12:00 UT turned
#                          into J2000 solar longitude, rounded outward to a degree
#   ra, dec                radiant at the peak, J2000 degrees (the IMO's; for the
#                          Draconids, whose calendar radiant moves with each year's
#                          predicted trails, the MDC median, between the two years)
#   dra, ddec              radiant drift, degrees of RA and Dec per degree of solar
#                          longitude (about per day): the median of the MDC's parameter sets
#   v_inf                  speed at entry, km/s (the IMO's; the MDC's geocentric speed
#                          agrees within 3 km/s)
#   r                      population index (the IMO's)
#   zhr                    typical peak zenithal hourly rate (the IMO's 2026 value;
#                          2 for the showers the IMO marks variable)
#   variable               1 when the rate varies from year to year or has had outbursts
#   parent                 parent body as the MDC gives it, blank when none is agreed
#
# The kappa-Cygnid radiant is the IMO's Table 6 position on the peak date (288, +54),
# not Table 5's (286, +59): Table 6 and the MDC agree on a radiant drifting north by
# 0.67 degrees a day. See the manifest for every check.
