# Deep-sky objects listed by SkyFix Lab. Display only (CONVENTIONS 13.6).
#
# Written for this project. The object selection, types, names and one-line
# descriptions are SkyFix Lab's own; positions and V magnitudes come from Wikidata
# (CC0) and are cross-checked against SIMBAD and Corwin's NGC/IC positions by
# tools/starfield/dso.py, which refuses the build on a disagreement it cannot explain.
#
# Selection. All 110 Messier objects, and SkyFix Lab's own choice of NGC/IC objects not
# in Messier's list, by this rule (magnitudes as adopted in our table):
#   1. open clusters with an integrated V of 5.0 or brighter;
#   2. globular clusters with V 7.5 or brighter;
#   3. galaxies with V 9.5 or brighter (with the two Magellanic Clouds);
#   4. planetary nebulae with V 9.5 or brighter;
#   5. emission and reflection nebulae and supernova remnants at least 30' across that
#      have a common name (the Lobster Nebula, NGC 6357, is left out: Wikidata's position
#      is 22' from both references);
#   6. four naked-eye clusters outside the NGC and IC: the Hyades, the Alpha Persei
#      Cluster, the Coma Star Cluster and the Coathanger.
#
# Format: id | type | size | name | description | extra
#   id    M1..M110, NGC<n>, IC<n>, or a short name for the few objects outside the NGC/IC
#   type  oc open cluster, gc globular cluster, pn planetary nebula, en emission nebula,
#         rn reflection nebula, snr supernova remnant, cn cluster with nebula, sg spiral
#         galaxy, eg elliptical galaxy, lg lenticular galaxy, ig irregular galaxy,
#         ds double star, as asterism, sc star cloud
#   size  apparent size in arcminutes, "major x minor" or one number, as commonly quoted
#         for the eye or a small telescope; blank = SIMBAD's, rounded (dso.py). Written
#         here where SIMBAD has none or gives a cluster's full extent (M21, M36, NGC 2362
#         and others) instead of what is seen.
#   name  common name, or blank
#   description  one line in our own words, or blank (the app then says "Open cluster
#         in Cassiopeia" and so on)
#   extra ';'-separated: ngc= other NGC/IC numbers (cross-identification), wikidata=
#         Wikidata item (objects without a Messier/NGC/IC code), simbad= SIMBAD
#         identifier when it differs, v= adopted V when Wikidata has none or a wrong
#         one (with vsrc= where it came from), corwin=none when Corwin has no position
