# The named lunar features SkyFix Lab shows, picked and described by this project.
#
# One line per feature: name | rank | description
#   name        exactly as the USGS/IAU Gazetteer of Planetary Nomenclature spells it;
#               or "Apollo NN" for a landing site, followed by "| source=<gazetteer name>"
#               naming the approved feature at the landing point whose coordinates it uses
#   rank        1 = a showpiece anyone should look for, 2 = notable, 3 = more to find
#   description one line in plain words, written for this project (not copied from any
#               list); Latin names are translated where it helps
#
# Coordinates, diameters and the feature type come from the gazetteer at build time
# (tools/moon/build.py); nothing numeric is typed here. The choice is this project's
# own: the near-side maria, the major craters and ranges, rilles, scarps and valleys
# that show well near the terminator, a few features in the libration zones, and the
# six Apollo landing sites.
